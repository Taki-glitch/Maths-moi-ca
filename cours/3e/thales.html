📏 Théorème de Thalès

Niveau : 3ème

📘 Cours

Le théorème de Thalès relie des longueurs dans des triangles avec des droites parallèles.
Si (DE) // (BC), alors AD/AB = AE/AC = DE/BC.
On utilise les égalités de rapports pour calculer une longueur inconnue.
Exemple : AD=4, AB=10, AC=15 donc AE=(4×15)/10=6.

✏️ Exercices d'entraînement

  1. Dans un triangle ABC, D∈[AB], E∈[AC], DE // BC. Avec AD=3, AB=9, AC=12, calculer AE.
  2. Toujours avec DE // BC, AD=5, AB=8, BC=14. Calculer DE.
  3. Rédiger la proportion de Thalès pour AD=2, AB=7, AE=3, AC=?, DE // BC.
  4. Vrai ou faux : si AD/AB = AE/AC alors (DE) // (BC) (dans la configuration adaptée).
  1. AE=(3×12)/9=4.
  2. DE=(5/8)×14=8,75.
  3. 2/7 = 3/AC donc AC = (7×3)/2 = 10,5.
  4. Vrai : c’est la réciproque de Thalès (avec points alignés dans le bon ordre).
