➕ Équations

Niveau : 4ème

📘 Cours

Résoudre une équation, c’est trouver la valeur de l’inconnue qui rend l’égalité vraie.
On effectue la même opération dans les deux membres pour conserver l’égalité.
On isole l’inconnue en simplifiant progressivement.
Exemple : 3x - 7 = 11 donc 3x = 18 puis x = 6.

✏️ Exercices d'entraînement

  1. Résoudre : x + 9 = 17.
  2. Résoudre : 5x = 45.
  3. Résoudre : 4x - 3 = 21.
  4. Résoudre : 2(x+3)=18.
  1. x = 8.
  2. x = 9.
  3. 4x=24 donc x=6.
  4. x+3=9 donc x=6.
