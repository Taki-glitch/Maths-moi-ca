⚡ Puissances

Niveau : 4ème

📘 Cours

Une puissance est une écriture abrégée d’un produit de facteurs égaux : a^n = a×a×...×a (n fois).
a^m × a^n = a^(m+n).
a^m / a^n = a^(m-n) (si a ≠ 0).
Exemple : 2^5 = 32 et 10^3 = 1000.

✏️ Exercices d'entraînement

  1. Écrire sous forme de puissance : 7×7×7×7.
  2. Calculer : A = 2^4 × 2^3.
  3. Calculer : B = 10^6 / 10^2.
  4. Écrire en notation scientifique : 4 500 000.
  1. 7^4.
  2. A = 2^(4+3)=2^7=128.
  3. B = 10^(6-2)=10^4=10 000.
  4. 4,5 × 10^6.
