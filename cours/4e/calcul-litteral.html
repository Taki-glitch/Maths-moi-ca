🧮 Calcul littéral

Niveau : 4ème

📘 Cours

Le calcul littéral utilise des lettres (x, y...) pour représenter des nombres inconnus ou variables.
Réduire une expression : regrouper les termes semblables (ex : 3x + 5x = 8x).
Développer : k(a+b)=ka+kb ; Factoriser : ka+kb=k(a+b).
Exemple : A=2(3x-4)+x = 6x-8+x = 7x-8.

✏️ Exercices d'entraînement

  1. Réduire : A = 4x + 7 - 2x + 3.
  2. Développer : B = 5(2x - 1).
  3. Factoriser : C = 9x + 27.
  4. Calculer D pour x = -2 : D = 3x² - x + 4.
  1. A = (4x-2x)+(7+3)=2x+10.
  2. B = 10x - 5.
  3. C = 9(x+3).
  4. D = 3×4 - (-2) + 4 = 12 + 2 + 4 = 18.
