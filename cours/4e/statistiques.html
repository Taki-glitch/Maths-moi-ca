📈 Statistiques

Niveau : 4ème

📘 Cours

Les statistiques permettent de collecter, organiser et interpréter des données.
Vocabulaire : effectif, fréquence, moyenne, médiane, étendue.
Moyenne = somme des valeurs / nombre de valeurs ; fréquence = effectif / total.
Exemple : notes 8, 10, 12 → moyenne 10 ; étendue 12-8=4.

✏️ Exercices d'entraînement

  1. Calculer la moyenne de : 9 ; 11 ; 13 ; 7.
  2. Dans une classe de 25 élèves, 10 pratiquent un sport en club. Donner la fréquence.
  3. Série : 2 ; 3 ; 3 ; 5 ; 7. Donner médiane et étendue.
  4. Comparer les moyennes de A: (12, 14, 10) et B: (9, 15, 12).
  1. (9+11+13+7)/4 = 40/4 = 10.
  2. f = 10/25 = 0,4 = 40%.
  3. Médiane = 3 ; étendue = 7-2 = 5.
  4. Moyenne A = 12 ; moyenne B = 12, donc égales.
