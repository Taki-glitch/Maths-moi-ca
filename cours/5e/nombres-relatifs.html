🔢 Nombres relatifs

Niveau : 5ème

📘 Cours

Un nombre relatif est un nombre positif, négatif ou nul. On le repère sur une droite graduée.
Opposés : deux nombres sont opposés s’ils ont la même distance à 0 et des signes contraires (ex : +7 et -7).
Comparaison : un nombre positif est toujours plus grand qu’un nombre négatif ; parmi deux nombres négatifs, le plus proche de 0 est le plus grand.
Calculs :
• Addition de même signe → on additionne les distances à 0 et on garde le signe.
• Addition de signes contraires → on soustrait les distances et on garde le signe du plus grand en valeur absolue.
Exemples : -3 + (-5) = -8 ; -9 + 4 = -5 ; (+6) - (+9) = -3.

✏️ Exercices d’entraînement

  1. Classer dans l’ordre croissant : +4 ; -2 ; 0 ; -7 ; +1.
  2. Calculer : A = -6 + 11 ; B = -8 + (-7) ; C = 12 - 15.
  3. Donner l’opposé de : -13 ; +5 ; 0.
  4. La température est de +3°C le matin puis baisse de 9°C. Quelle est la température finale ?
  1. -7 < -2 < 0 < +1 < +4.
  2. A = 5 ; B = -15 ; C = -3.
  3. Opposés : +13 ; -5 ; 0.
  4. +3 - 9 = -6 : température finale -6°C.
